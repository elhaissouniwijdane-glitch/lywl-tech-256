# Technologies

## Programming language

**Python 3**

Used to implement the game logic, manage events and organize the different components.

## Library

**Pygame**

Used for:
- 2D rendering
- Sprite animations
- Keyboard input handling
- Collision detection
- Sound management

## Development tools

- Git: version control
- GitLab: collaborative source code management
- GitHub: project hosting and documentation

## Concepts

- Object-oriented programming
- Modular architecture
- Event handling
- Collision detection
- Random obstacle generation
- Score management
